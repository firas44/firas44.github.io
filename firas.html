01 · About

An engineer who owns the whole stack, and the outcome.

I build software that solves problems off-the-shelf tools couldn't, then I make it secure, fast and reliable enough to trust with real people's data.

At Tikshoov I work as a one-person engineering function. I gather requirements with government ministries, enterprise vendors and stakeholders, then design the architecture, write the backend and frontend, wire up cloud and third-party integrations, and keep it all running in production. That's how secure payroll, CRM & CMS, payments and queue management, BI dashboards and national-scale survey platforms got built from scratch.

I also care how things look and feel. Clean UI, clear information and fast pages are part of the engineering for me. Lately I've been leaning hard into AI-augmented engineering, using LLMs to ship faster and building AI-powered automation into the products I deliver.

★ OPEN SOURCE · PERSONAL PROJECT

RigWatch

Your whole PC on one page.

A zero-dependency Node.js system monitor that replaces Task Manager, Resource Monitor, an FPS overlay and netstat. It shows per-thread CPU, GPU per engine and per-process VRAM, FPS with 1% lows, every temperature sensor, disk latency, and every listening port, with each running dev server labeled by project. All of it streams live over Server-Sent Events.

  • Security built in: localhost binding, Host-header checks against DNS rebinding, and secrets masked out of command lines
  • About 1% CPU overhead: long-lived PowerShell workers read perf counters, WMI and ETW in bulk
  • Plain JSON API, dark & light themes, works on a phone
